# Security

Report suspected vulnerabilities privately through GitHub's security advisory
flow for this repository.

Do not open a public issue containing:

- unrevealed Holo or Growl data;
- decryption material;
- signing keys;
- customer information;
- exploit details that would expose an active deployment.

Holodex is a static, GET-only publication surface. It never accepts credentials,
payments, trades, orders, or private customer content.
